# offline-exec-rules (단독망 실행 규율)

[base-rules](base-rules.md)를 상속한다. 이 머신은 **단독망**(외부 인터넷 차단)이며
추론은 **로컬 ollama 모델**(`f-ollama`)로 한다. 아래 규율을 모든 작업에 적용한다.

## 1. 네트워크 (단독망)
- WebSearch·WebFetch·외부 API 호출·인터넷 패키지 설치를 **시도하지 않는다**.
  필요하면 멈추고 사용자에게 보고한다(자동 우회 금지).
- 추론 엔드포인트는 로컬 `f-ollama` 컨테이너만 사용한다.

## 2. 종료 조건 (모호 금지)
- 모든 루프·반복 작업에 **명확한 종료 조건**을 명시한다("완료 시 중단"을 구체 조건으로).
- "시도해봐 / 필요 시 / 적당히" 같은 모호 표현 금지 → if-조건 + 수치로 기술한다.

## 3. 재시도·상한
- 외부 명령 실패 시 재시도 **1회**. 2회 연속 실패면 즉시 사용자 보고 후 대기.
- 파일 반복 최대 50개, 에이전트 호출 최대 3회 초과 시 분할·보고한다.

## 4. 무거운 작업 라우팅
- 빌드·장시간 추론은 Remote(`sma`)로 라우팅한다(base-rules 4절).

## 5. 승인 필수
- 파일 삭제·`git reset --hard`·force-push·컨테이너/모델 삭제는 사용자 승인 후 수행한다.
