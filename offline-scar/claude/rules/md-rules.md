# md-rules (마크다운 규약)

[base-rules](base-rules.md)를 상속한다. 모든 `.md` 산출물에 적용한다.

## 프런트매터 (필수)
- 모든 문서 첫머리에 YAML 프런트매터를 둔다.
- `name`(=파일명, 확장자 제외) **또는** `title`(제목이 파일명과 다를 때)을 하나만 쓴다.
- 권장 필드: `name|title`, `description`, 필요 시 `date`(`date +%Y-%m-%d`로 확인, 추측 금지).
- `description`이 있으면 본문 첫 줄에 같은 설명을 반복하지 않는다.

## 아웃라인
- 프런트매터 `name/title`이 문서 제목이므로 본문에 중복 `# 제목` H1을 두지 않는다.
    - 예외: 한 파일에 독립 섹션 H1이 여럿인 트래커형 파일(`Issue.md` 등).
- 헤더 레벨을 건너뛰지 않는다. H1 아래 H2, H2 아래 H3 (H1→H3 금지).

## 불릿
- 1단계 `*`, 2단계 이하 `-`.

## 표
- 셀을 열의 최대 너비에 맞춰 공백 패딩 정렬한다. 값·순서는 바꾸지 않고 정렬만 적용한다.
